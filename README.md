# 🍕 Food Lover Restaurant

A multi-section restaurant landing page designed with semantic **HTML5** and custom modern **CSS3**, featuring dish showcases, a categorized menu, daily operating hours, a photo gallery, and an integrated reservation form.

🔗 **Live Demo:** [khaledcherfouhi2006-maker.github.io/food-lover](https://khaledcherfouhi2006-maker.github.io/food-lover/)

---

## ✨ Features

- **Hero Landing Area:** Full-screen background cover with branded navigation, header slogan, and a prominent "Book a Table" call-to-action button.
- **Story & History Section:** Informative narrative covering over 25 years of restaurant tradition and food preparation expertise.
- **Special Offers:** Highlighted pasta and specialty items displaying regular and discounted promotional pricing.
- **Two-Column Menu:** Organized selections detailing appetizers, main courses, pizzas, and beverages with individual descriptions and prices.
- **Daily Service Timetable:** Dedicated schedule section outlining operational periods for Breakfast, Lunch, Dinner, and Dessert.
- **Food Gallery Grid:** Responsive photo grid showcasing signature culinary preparations.
- **Contact & Reservation Area:** Detailed branch information (address, working hours, social links) paired with an interactive table booking form.
- **Smooth Navigation:** Internal anchors enabling smooth scrolling transitions across sections.

---

## 🛠️ Built With

- **HTML5:** Semantic elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`), structured forms, and meta configurations.
- **CSS3:** Custom layout architectures with Flexbox and CSS Grid, background cover styling, button transition states, and the *Quicksand* web font.
- **Font Awesome (v6.4.2):** Scalable icons for contact items, social links, and navigation tags.
- **GitHub Pages:** Static site hosting and deployment.
